# ShellAX Windows x64 测试说明（0.1.5 预览版）

这个 0.1.5 预览版在 Windows 上原生编译（x86_64-pc-windows-gnu），渲染用 DirectX 11 + DirectWrite。请按下面的清单测试，并把问题反馈回来。

## 系统要求
- Windows 10 1903 及以上，或 Windows 11，64 位。程序依赖系统自带的 icuuc.dll，1903 之前的 Windows 10 没有这个文件。
- 显卡需要支持 Direct3D 11，虚拟机要开启 3D 加速。
- 不需要安装 VC++ 运行库，C 运行库已静态链接。

## 安装（二选一）
1. 安装包 `ShellAX-Setup-x64.exe`
   - 双击运行。只装给当前用户，**不需要管理员权限**，默认装到 `%LOCALAPPDATA%\Programs\ShellAX`。
   - 安装后会创建开始菜单项“ShellAX”、桌面快捷方式，以及开始菜单里的“Uninstall ShellAX”。
   - 卸载：可以在“设置 → 应用 → 已安装的应用”里卸载，也可以用开始菜单里的卸载项。卸载**不会删除**你的配置和数据（见下文）。
2. 便携版 `ShellAX-portable-x64.zip`
   - 解压到任意目录，双击 `shellax.exe` 即可。配置和数据的位置与安装版相同。

## SmartScreen / 杀毒软件提示
安装包和 exe 都**没有代码签名**，第一次运行时 Windows SmartScreen 可能会提示“Windows 已保护你的电脑”。点 **“更多信息” → “仍要运行”** 即可。浏览器下载时也可能提示“不常下载”，选“保留”。如果杀毒软件误报，请告诉我软件名称和报毒名称。

## 配置与日志位置
| 内容 | 路径 |
|---|---|
| 配置文件 | `%APPDATA%\ShellAX\config.toml`（第一次在设置里改动后才会生成） |
| 自定义主题 / 右键菜单 | `%APPDATA%\ShellAX\themes\`，`%APPDATA%\ShellAX\context_menu.toml` |
| 运行日志 | `%LOCALAPPDATA%\shellax\logs\shellax.log`（上一次运行的日志是 `shellax.old.log`，崩溃信息也写在这里） |
| 审计日志、历史、会话快照、加密凭据 | `%LOCALAPPDATA%\shellax\` |
| SSH 配置 / 密钥 / known_hosts | `%USERPROFILE%\.ssh\` |

**反馈问题时请附上 `shellax.log`。** 在资源管理器地址栏输入 `%LOCALAPPDATA%\shellax\logs` 就能打开这个目录。

## 验证清单
请逐项填写“通过 / 不通过 / 现象”：

- [ ] **启动**：窗口能正常出现，左上角有自绘的红黄绿三个按钮，标签和标题栏在同一行；可以拖动、双击最大化、拖边缘调整大小；最小化、关闭按钮正常
- [ ] **字体**：界面用 Segoe UI，中文用微软雅黑，没有方框或乱码；终端用 Cascadia Mono（Win11 自带），没有的话会自动换成 Consolas；中文、粗体、Powerline、Emoji 显示正常
- [ ] **高 DPI**：在 125% / 150% 缩放下文字清晰，没有模糊；窗口在不同 DPI 的显示器之间拖动时显示正常
- [ ] **输入法**：在终端和设置搜索框里用微软拼音（或你常用的输入法）输入中文，候选窗跟随光标，上屏正确，不重复、不丢字
- [ ] **透明效果**：弹窗、右键菜单、命令面板（Ctrl+Shift+P）有半透明背景、圆角、阴影和淡入动画。Windows 上侧边栏**不是毛玻璃**，而是不透明背景，这是预期行为
- [ ] **主题**：默认跟随系统深色/浅色，即 macOS Light / Dark 主题；在设置 → 外观里能切换到其他主题
- [ ] **本地终端**：新建本地标签（Ctrl+Shift+N）默认启动 PowerShell 7（pwsh），没有装的话启动 Windows PowerShell；能执行 `dir`、`ping`、`ssh -V`；窗口大小变化后排版正确
- [ ] **SSH 连接**：添加主机，用密码 / 私钥 / 带密码短语的私钥连接；首次连接会弹出主机指纹确认，之后不再提示。如果开了 Windows OpenSSH 的 ssh-agent 服务或 Pageant，看能否用 agent 中的密钥登录
- [ ] **SFTP**：在主机右键菜单里依次用弹窗、标签页、分屏、独立窗口打开 SFTP；上传、下载、重命名、删除、新建文件夹都正常；路径里有中文或空格也正常；从资源管理器拖入文件能上传
- [ ] **AI 配置**：设置 → AI 里填写服务地址和 API Key，保存后重启程序 Key 还在（存在 Windows 凭据管理器里）；能拉取模型列表；AI 对话和自然语言转命令能用
- [ ] **空闲内存 / CPU**：打开 1 个本地标签和 1 个 SSH 标签后空闲 1 分钟，在任务管理器里看内存（PRD 目标是 80 MB 以下；Linux 软件渲染下实测 RSS 约 169 MB，大部分是软件渲染器占用，真实 GPU 下应该更低）和 CPU（空闲时应接近 0%）
- [ ] **通知**：长命令结束或 Agent 等待确认时，有 Windows 通知弹出
- [ ] **卸载**：卸载后开始菜单项、桌面快捷方式和安装目录都被删除；`%APPDATA%\ShellAX` 保留

## 0.1.2 新增验证项
- [ ] **设置 → 代理**：第一次打开会自动检测本机代理（系统代理 / 环境变量 / 本机端口），在检测结果里点“使用”即可填入；也可以手动选 SOCKS5 或 HTTP、填地址和端口（端口填成 0 或 70000 会提示 1–65535）、需要认证时填用户名密码。保存后显示“当前：…”，点“清除”恢复直连。
- [ ] **不走代理的主机**：通配、逗号分隔；命中的地址即使这台连接开了代理也直连，用来排除本机和内网。如果系统或环境变量里带了排除项，界面上会建议出来，可一键“填入排除列表”。
- [ ] **每台连接单独开代理**：主机对话框里的「使用代理」开关。打开并保存后，只有这台连接经设置里的本机代理出去，其他连接不受影响；带跳板机时，开关作用于真正离开本机的那一跳（不是内网那一跳）。
- [ ] **没填代理地址时的提示**：打开「使用代理」但设置里还没有代理地址时，对话框出现黄色提示和“去设置”按钮；点“测试连接”或直接连接会先提示去填地址，**不会悄悄改成直连**。
- [ ] **AI 与更新也走代理**：保存代理后，AI 请求和更新检查使用同一个地址，不看每台连接的开关；填了“不走代理的主机”时，命中的地址连 AI 请求也直连。
- [ ] **选择私钥**：主机对话框私钥输入框旁的“选择”会列出 `~/.ssh` 里的私钥（文件名 + 类型 + 指纹），点一条即填入；`~/.ssh` 下没有私钥时给出提示而不是空列表。
- [ ] **只用一个私钥**：认证方式选「密钥」并选好私钥后，只用这一个文件登录（不再顺带回退 `id_ed25519` / `id_ecdsa` / `id_rsa`）；认证方式为「自动」时仍按顺序回退。可以用一把不在默认位置、默认名字（例如 `shellax_ed25519`）的私钥验证。
- [ ] **复制公钥**：设置 → 凭据与密钥里每把私钥都有“复制公钥”，把 `~/.ssh/<私钥名>.pub` 的第一行复制到剪贴板，可直接粘到 GitHub / 服务器；没有对应 `.pub` 或文件为空时给出提示。

## 已知限制（Windows 版）
- 会话守护进程（关闭窗口后本地 shell 继续运行）目前只支持 Linux/macOS，Windows 上关闭窗口就会结束本地 shell。
- 本地终端里的“前台进程识别”（自动认出 claude / codex 等 Agent）依赖 Unix 接口，Windows 上暂时关闭。通过 Agent 钩子上报的状态不受影响。
- 系统托盘图标目前只支持 Linux。
- 没有代码签名，也没有自动更新安装（更新检查只会提示有新版本）。
